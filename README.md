## Análise de dados com Python 🐍

Meu fluxo de trabalho ao atacar um problema com dados:

```text
1. Coleta        →  SQL, API REST, CSV, Excel
2. Tratamento    →  pandas: limpeza, tipos, nulos, duplicatas
3. Exploração    →  estatística descritiva, distribuições, correlações
4. Visualização  →  Matplotlib / Seaborn / Power BI
5. Conclusão     →  o número vira recomendação de negócio
```

O que me interessa não é a biblioteca — é a pergunta. Análise que não muda uma decisão é relatório bonito e nada mais.
